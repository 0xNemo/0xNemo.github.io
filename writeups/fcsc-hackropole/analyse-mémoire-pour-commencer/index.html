Description

Vous vous préparez à analyser une capture mémoire et vous notez quelques informations sur la machine avant de plonger dans l’analyse :

  • nom d’utilisateur,
  • nom de la machine,
  • adresse IPv4, non locale, de la machine. Le flag est au format FCSC{<nom d'utilisateur>:<nom de la machine>:<adresse IPv4>}

Challenge - partie 1

Identification

Pour analyser ce dump mémoire, on utilise Volatility

Volatility est un framework open-source d’analyse forensique de mémoire vive (RAM), Il permet d’extraire des artefacts numériques comme les processus actifs, les connexions réseau, les clés de registre ou les mots de passe directement depuis un dump mémoire.

On commence par trouver l’OS de la machine sur laquelle on a fait une capture mémoire, le plugin banners ne renvoie rien, on essaye logiquement avec Windows :

C’est un Windows 10 64bits - Is64Bit True + NtMajorVersion 10

Nom d’utilisateur

On peut récupérer facilement le nom d’utilisateur avec le plugin volatility registry.hashdump qui récupère les hash ntlm des utilisateurs Windows, il affiche également le username :

Username : userfcsc-10

Nom de la machine

Le registre Windows est une base de données qui stocke les configurations système, les paramètres utilisateurs, les paramètres des soft installés etc. Le nom de la machine est une donnée de configuration qui se trouve dans le registre. Quelques sources nous donnent la clée : \SYSTEM\CurrentControlSet\Control\ComputerName\ActiveComputerName comme ici superuser - find hostname

Le plugin registry.hivelist liste les ruches présentes dans l’image mémoire. On peut récupérer l’offset de la ruche SYSTEM puis essayer de récupérer la clée ActiveComputerName. La clée essayée ne fonctionne pas, alors on dump la ruche SYSTEM directement qu’on analyse avec Registry Explorer de Eric Zimmerman.

Nom de la machine : DESKTOP-JV996VQ

(Il y des plugins qui permettent de sortir directement le nom de la machine comme sessions, envars, etc. mais j’ai voulu faire comme ça)

IP de la machine

le plugin volatility NetScan scan les connexions réseaux identifiées dans la capture mémoire. Et pour les même raison que le Nom de la machine, l’ip est stockée dans la ruche SYSTEM. Source : superuser - ip address in regtistry -> SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces

IP : 10.0.2.15

Flag : FCSC{userfcsc-10:DESKTOP-JV996VQ:10.0.2.15}

Challenge - partie 2

La capture mémoire a été réalisée pendant qu’un utilisateur était en train de travailler sur un document hautement sensible. Si une compromission du poste a eu lieu, ce document a peut-être été volé. Pouvez-vous retrouver :

  • le nom du logiciel d’édition du document,
  • le nom du document.

Edition du document

On imagine que le logiciel qui édite le fichier a lancé une ligne de commande avec le nom du fichier en parmètre. Le plugin windows.cmdline liste les lignes de commande et leurs arguments, des process qui sont lancés.

Flag : FCSC{soffice.exe:[SECRET-SF][TLP-RED]Plan FCSC 2026.odt}
